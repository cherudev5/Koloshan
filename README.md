# Koloshan

Koloshan is a modern printing company website built with React, Vite, and Tailwind CSS.

## Features

- Responsive design
- Company profile
- Services section
- Portfolio gallery
- Customer testimonials
- Contact form
- WhatsApp integration
- Scroll-to-top button

## Technologies

- React
- Vite
- Tailwind CSS
- React Icons
- Framer Motion

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
